    "# AI Job Hunter Agent  \n",
    "\n",
    "An AI-powered job search and application assistant designed to discover relevant job opportunities, evaluate their suitability, and prepare personalized application materials while keeping the final application decision under human control.\n",
    "\n",
    "## 🎯 Project Goal\n",
    "\n",
    "The goal of this project is to build an AI agent that can automate much of the job-search process while maintaining human oversight.\n",
    "\n",
    "The agent will search selected online job platforms **twice per week**, identify newly published vacancies, analyze them, and determine how closely each opportunity matches a predefined candidate profile.\n",
    "\n",
    "## 🤖 Planned Workflow\n",
    "\n",
    "The system will eventually perform the following pipeline:\n",
    "\n",
    "**Search → Extract → Analyze → Score → Select → Customize → Review → Apply**\n",
    "\n",
    "### 1. Job Discovery\n",
    "\n",
    "The agent will periodically search selected job platforms for newly published vacancies.\n",
    "\n",
    "It will collect relevant information such as:\n",
    "\n",
    "* Job title\n",
    "* Company\n",
    "* Location\n",
    "* Working hours\n",
    "* Remote/hybrid options\n",
    "* Salary information\n",
    "* Required skills\n",
    "* Required experience\n",
    "* Language requirements\n",
    "* Job description\n",
    "* Application deadline\n",
    "\n",
    "### 2. Job Matching\n",
    "\n",
    "Each job will be analyzed against a structured candidate profile containing information such as:\n",
    "\n",
    "* Professional skills\n",
    "* Previous experience\n",
    "* Education\n",
    "* Languages\n",
    "* Preferred job types\n",
    "* Working-hour availability\n",
    "* Location preferences\n",
    "* Salary expectations\n",
    "* Career goals\n",
    "\n",
    "The system will assign each vacancy a **match score** and explain why the position is or is not suitable.\n",
    "\n",
    "Example:\n",
    "\n",
    "```text\n",
    "Match Score: 86/100\n",
    "Recommendation: APPLY\n",
    "\n",
    "Strong matches:\n",
    "+ Python and data-analysis skills\n",
    "+ English accepted\n",
    "+ Flexible working arrangement\n",
    "+ Relevant analytical responsibilities\n",
    "\n",
    "Potential concerns:\n",
    "- Power BI experience preferred\n",
    "- Some travel may be required\n",
    "```\n",
    "\n",
    "### 3. AI Model\n",
    "\n",
    "The project will explore suitable open-source models, including models available through Hugging Face.\n",
    "\n",
    "Possible approaches include:\n",
    "\n",
    "* Large Language Models (LLMs)\n",
    "* Sentence-transformer / embedding models\n",
    "* Semantic similarity\n",
    "* Classification models\n",
    "* Retrieval and ranking systems\n",
    "\n",
    "Depending on performance, the selected model may be used directly, fine-tuned, or combined with rule-based filtering.\n",
    "\n",
    "### 4. Application Preparation\n",
    "\n",
    "For high-scoring jobs, the agent will prepare customized application materials based on the vacancy.\n",
    "\n",
    "This may include:\n",
    "\n",
    "* Tailored CV\n",
    "* Cover letter\n",
    "* Motivation letter\n",
    "* Application-form answers\n",
    "* Skills summaries\n",
    "* Responses to employer questions\n",
    "\n",
    "The system must not invent qualifications or experience.\n",
    "\n",
    "### 5. Human Approval\n",
    "\n",
    "The agent will **never submit an application automatically without approval**.\n",
    "\n",
    "Before submission, it will present:\n",
    "\n",
    "* The job posting\n",
    "* Match score\n",
    "* Reasons for recommending the position\n",
    "* Customized CV\n",
    "* Customized cover letter\n",
    "* Proposed answers to application questions\n",
    "\n",
    "The user can then:\n",
    "\n",
    "**Approve → Edit → Reject**\n",
    "\n",
    "Only approved applications may proceed to submission.\n",
    "\n",
    "## 🛠️ Planned Technology\n",
    "\n",
    "* Python\n",
    "* Hugging Face\n",
    "* Git / GitHub\n",
    "* NLP / LLMs\n",
    "* Job APIs and permitted web sources\n",
    "* Browser automation where appropriate\n",
    "* Structured candidate profile\n",
    "* Local database for jobs and application history\n",
    "\n",
    "## 📂 Planned Project Structure\n",
    "\n",
    "```text\n",
    "job-hunter-agent/\n",
    "│\n",
    "├── README.md\n",
    "├── requirements.txt\n",
    "├── data/\n",
    "├── models/\n",
    "├── src/\n",
    "│   ├── job_search/\n",
    "│   ├── job_matching/\n",
    "│   ├── document_generator/\n",
    "│   └── application_agent/\n",
    "├── tests/\n",
    "└── notebooks/\n",
    "```\n",
    "\n",
    "## 🚧 Development Roadmap\n",
    "\n",
    "**Phase 1 — Candidate Profile**\n",
    "Create a structured representation of the candidate's skills, experience, preferences, and constraints.\n",

    "Build a system capable of comparing a job description with the candidate profile and producing a meaningful match score.\n",
    "\n",
    "**Phase 3 — Job Discovery**\n",
    "Connect the system to permitted job sources and automatically discover new vacancies.\n",
    "\n",
    "**Phase 4 — Application Generation**\n",
    "Generate tailored CVs, cover letters, and application responses.\n",
    "\n",
    "**Phase 5 — Agent Workflow**\n",
    "Combine discovery, evaluation, document generation, and approval into an automated pipeline.\n",
    "\n",
    "**Phase 6 — Scheduled Job Hunting**\n",
    "Run the agent twice per week and process newly published vacancies.\n",
    "\n",
    "## 🔐 Design Principle\n",
    "\n",
    "**Automation with human control.**\n",
    "\n",
    "The system should reduce repetitive job-search work while keeping important decisions — particularly the final submission of an application — under the user's control.\n",
